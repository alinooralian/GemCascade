<< Cascade Gem Game >>
Cascade Gem is a console-based Match Puzzle Game implemented in C++.

-Objective:

The goal of the game is to reach the target score before running out of moves.
Each difficulty level has a different number of available moves and a different target score.

-Controls:

W : Swap two adjacent gems
H : Get a Hint (-70 score)
B : Use Bomb (-100 score)
R : Use Rocket (-120 score)
S : Save the current game
Q : Quit the game

-Matching Rules:

A match consists of 3 or more connected gems of the same type.
+Matching 3 gems removes those gems.
+Matching 4 gems activates a special effect that clears an entire row or column.
+Matching 5 gems removes all gems of the same type from the board.

-Cascade System:

After gems are removed:
Empty spaces are created.
Remaining gems fall down due to gravity.
New gems are generated at the top.
New matches are automatically removed.
This process continues until no more matches remain.

-Special Powers:

+Bomb
	Removes a 3x3 area centered around the selected cell.
	Cost: 100 score points.
+Rocket
	Removes an entire row or column.
	Cost: 120 score points.
+Hint
	Shows the best available move.
	Cost: 70 score points.

-Difficulty Levels:

+Easy
	50 Moves
	Target Score: 14720
+Medium
	30 Moves
	Target Score: 5830
+Hard
	10 Moves
	Target Score: 3530

-Winning Condition:
Reach or exceed the target score before your moves run out.

-Losing Condition:
Run out of moves before reaching the required score.
